# 🚀 Day 30 – Full CRUD Operations

Welcome to **Day 30 of my 50-Day Web Development Challenge!** 🎉

Today, I worked with **Full CRUD Operations** and learned how frontend applications can create, read, update, and delete data through API requests.

## 📌 What I Learned

* Understanding CRUD architecture
* **Create** data using `POST`
* **Read** data using `GET`
* **Update** data using `PUT` / `PATCH`
* **Delete** data using `DELETE`
* Working with REST APIs
* Using the Fetch API
* Handling JSON data
* Managing asynchronous requests with `async/await`
* Dynamically rendering API data
* Updating the UI after API operations
* Handling loading and error states

## ✨ Key Features

* ➕ Create new records
* 👀 Fetch and display existing records
* ✏️ Edit and update records
* 🗑️ Delete records
* 🔄 Dynamically refresh the interface
* ⏳ Loading state handling
* ❌ Error handling
* 📱 Responsive UI

## 🛠️ Technologies Used

* HTML5
* CSS3

* Fetch API
* REST API
* JSON

* HTTP Methods

* Git & GitHub

## 🎯 Day 30 Goal

The goal was to build a complete data-management workflow using all four fundamental CRUD operations:

```text
CREATE  →  POST
READ    →  GET
UPDATE  →  PUT / PATCH
DELETE  →  DELETE
```

Successfully implemented a complete **CRUD-based application** that communicates with an API and dynamically updates the interface.
