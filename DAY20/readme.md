# 🚀 Day 20 – Stateful Task Tracker

Welcome to **Day 20 of my 50-Day Web Development Challenge!**

Today, I built a **Stateful Task Tracker** using JavaScript, combining DOM manipulation, event handling, and Local Storage to create an interactive task management application.

## 📌 What I Learned

* Understanding application state
* Creating and managing tasks dynamically
* Adding and deleting tasks
* Marking tasks as completed
* Updating the UI based on state changes
* Event handling and Event Delegation
* Using Local Storage for data persistence
* Saving and retrieving task data
* Rendering tasks dynamically
* Keeping application state and UI synchronized

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM API
* Local Storage
* Event Delegation
* VS Code
* Git & GitHub

## 🎯 Day 20 Goal

The goal was to build a task tracker where the **application state controls the UI**, while ensuring that tasks remain saved even after refreshing the webpage.


## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 💾 Persist tasks using Local Storage
* 🔄 Dynamically update the task list
* 📱 Responsive interface

## 💡 Outcome

Successfully created a functional **stateful task management application** and gained a stronger understanding of how JavaScript state, DOM rendering, events, and Local Storage work together.
