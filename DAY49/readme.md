## ✨ Features

### SPA Router

The application uses hash-based routing:

#/ 
#/users
#/data
#/about

Views are dynamically inserted into:

#app-root

without reloading the complete webpage.

### API Data Streams

The application communicates with the GitHub REST API.

### Fetch Retry

Failed network requests are retried automatically.

### Promise.all()

Multiple API requests are performed concurrently.
