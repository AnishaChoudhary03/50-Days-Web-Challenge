# 🚀 Day 4 – Component Design

Welcome to **Day 4 of my 50-Day Web Development Challenge!**

Today, I focused on **Component Design** and learned how to create reusable, consistent, and well-structured UI components for a website.

## 📌 What I Learned

* Understanding UI components
* Creating reusable components
* Designing buttons, cards, navigation bars, and sections
* Maintaining consistent spacing and alignment
* Using reusable CSS classes
* Creating visually consistent layouts
* Organizing HTML and CSS for better maintainability
* Improving user interface structure and readability

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* VS Code
* Git & GitHub

## 🎯 Day 4 Goal

The goal was to understand how individual UI elements can be designed as **reusable components** and combined to create a clean and consistent webpage.


## 💡 Outcome

Successfully designed and implemented reusable UI components while improving the overall structure, consistency, and appearance of the webpage.
