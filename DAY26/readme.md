# 🚀 Day 26 – Dynamic GitHub Repository Rendering

Welcome to **Day 26 of my 50-Day Web Development Challenge!**

Today, I extended the **Community Contributor Lookup** project by moving beyond fetching a single GitHub user profile and dynamically displaying their latest open-source repositories.

## 📌 What I Learned

* Working with external APIs
* Using the GitHub REST API
* Fetching repository data with `fetch()`
* Handling asynchronous JavaScript
* Using `async/await`
* Processing JSON responses
* Dynamically rendering arrays of data
* Creating reusable repository cards
* Handling loading and error states
* Displaying repository information in a responsive grid

## ✨ Key Features

* 🔍 Search for a GitHub developer
* 👤 Display contributor profile information
* 📦 Fetch recently updated public repositories
* 🃏 Dynamically generate repository cards
* ⭐ Display repository stars
* 💻 Display programming languages
* 🔗 Provide links to repositories
* ⚡ Handle loading and API errors
* 📱 Responsive repository grid

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* Fetch API
* GitHub REST API
* DOM Manipulation
* Async/Await
* VS Code
* Git & GitHub

## 🎯 Day 26 Goal

The goal was to transform the project from a **single-profile lookup tool into a dynamic repository explorer**.

Instead of hardcoding project cards, repository information is fetched from the GitHub API and rendered automatically based on the selected contributor.


## 💡 Outcome

Successfully integrated live GitHub repository data and dynamically rendered repositories as project cards.

This strengthened my understanding of **API integration, asynchronous JavaScript, dynamic rendering, and data-driven UI development**.
