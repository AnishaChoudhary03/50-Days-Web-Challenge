# 🚀 Day 24 – SPA Routing

Welcome to **Day 24 of my 50-Day Web Development Challenge!**

Today, I explored **Single Page Application (SPA) Routing** and learned how modern web applications navigate between different views without completely reloading the webpage.

## 📌 What I Learned

* Understanding Single Page Applications
* Client-side routing
* Using the Browser History API
* `history.pushState()`
* `history.replaceState()`
* Handling the `popstate` event
* Updating the URL without reloading the page
* Dynamically rendering page content
* Handling navigation links
* Creating a basic Vanilla JavaScript router

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM API
* History API
* `pushState()`
* `popstate`
* VS Code
* Git & GitHub

## 🎯 Day 24 Goal

The goal was to build a simple **client-side router** that allows users to navigate between different views while keeping the application on a single HTML page.



## ✨ Key Features

* 🧭 Client-side navigation
* ⚡ No full-page reload
* 🔗 URL updates using the History API
* 🔄 Dynamic content rendering
* ⬅️ Browser back and forward support
* 📱 Responsive interface

## 💡 Outcome

Successfully created a basic **Vanilla JavaScript SPA Router** and gained a better understanding of how modern web applications provide fast, app-like navigation without repeatedly reloading the entire page.
