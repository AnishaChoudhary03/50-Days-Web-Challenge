# 🚀 Day 29 – API POST Request

Welcome to **Day 29 of my 50-Day Web Development Challenge!**

Today, I focused on understanding how to send data from a frontend application to a server using an **HTTP POST request**.

## 📌 What I Learned

* Difference between GET and POST requests
* Using the Fetch API for POST requests
* Sending data to an external API
* Creating request bodies with JSON
* Setting HTTP request headers
* Using `Content-Type: application/json`
* Handling asynchronous API requests
* Processing server responses
* Handling successful and failed requests
* Form data submission using JavaScript

## ✨ Key Features

* 📝 Collect data through a form
* 📦 Convert form data into JSON
* 🌐 Send data using a POST request
* 🔐 Set appropriate request headers
* ⚡ Handle API responses dynamically
* ✅ Display successful submission feedback
* ❌ Handle API errors gracefully

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* Fetch API
* REST API
* HTTP POST
* JSON
* Async/Await
* VS Code
* Git & GitHub

## 🎯 Day 29 Goal

The goal was to move beyond consuming data from APIs and learn how to **send user-generated data to a server** securely and correctly using a POST request.



## 💡 Outcome

Successfully implemented an API **POST request** to package form data as JSON, configure the required headers, send the payload to a server, and handle the response.
