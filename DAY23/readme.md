# 🚀 Day 23 – Drag and Drop

Welcome to **Day 23 of my 50-Day Web Development Challenge!**

Today, I explored the **HTML Drag and Drop API** and learned how to create interactive interfaces where users can move elements between different areas.

## 📌 What I Learned

* Understanding the Drag and Drop API
* `dragstart` event
* `dragover` event
* `drop` event
* `dragend` event
* Using `dataTransfer`
* Handling drag events with JavaScript
* Moving elements dynamically
* Creating interactive drop zones
* Preventing default browser behavior during drag events

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Drag and Drop API
* DOM API
* VS Code
* Git & GitHub

## 🎯 Day 23 Goal

The goal was to understand how drag-and-drop interactions work and build an interface where users can **drag elements and drop them into designated areas**.

## ✨ Key Features

* 🖱️ Drag elements using the mouse
* 📦 Drop elements into designated zones
* 🔄 Dynamically move elements
* 🎯 Visual feedback for drop areas
* ⚡ Interactive JavaScript-based behavior

## 💡 Outcome

Successfully implemented a functional **Drag and Drop interface** and gained practical experience with browser events, the DOM, and the HTML5 Drag and Drop API.
