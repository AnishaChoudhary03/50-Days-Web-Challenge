# 🚀 Day 6 – Responsive Web Design

Welcome to **Day 6 of my 50-Day Web Development Challenge!**

Today, I focused on **Responsive Web Design** and learned how to make websites adapt smoothly to different screen sizes and devices.

## 📌 What I Learned

* Introduction to responsive design
* CSS Media Queries
* Mobile-first approach
* Responsive layouts
* Flexible widths and heights
* Using relative units like `%`, `rem`, and `vw`
* Responsive images
* Adjusting layouts for tablets and mobile devices
* Combining Flexbox and Grid for responsive designs

## 🛠️ Technologies Used

* HTML5
* CSS3
* Media Queries
* Flexbox
* CSS Grid
* VS Code
* Git & GitHub

## 🎯 Day 6 Goal

The goal was to create a webpage that provides a consistent and user-friendly experience across **desktops, tablets, and mobile devices**.


## 💡 Outcome

Successfully made the webpage responsive and gained a better understanding of how modern websites adapt to different screen sizes.
