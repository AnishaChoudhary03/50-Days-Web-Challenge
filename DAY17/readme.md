# 🚀 Day 17 – Theme Engineering

Welcome to **Day 17 of my 50-Day Web Development Challenge!**

Today, I focused on **Theme Engineering** and explored how to create a consistent, scalable, and customizable visual system for a website.

## 📌 What I Learned

* Understanding design themes
* Creating consistent color palettes
* CSS Custom Properties (Variables)
* Managing typography and spacing
* Creating reusable design tokens
* Maintaining visual consistency across components
* Implementing Light and Dark themes
* Using JavaScript to switch themes
* Saving theme preferences using Local Storage

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Custom Properties
* Local Storage
* DOM API
* VS Code

## 🎯 Day 17 Goal

The goal was to build a flexible **theme system** that allows the website's colors, typography, spacing, and visual elements to remain consistent while making it easy to switch between different themes.


## 💡 Outcome

Successfully created a reusable theme system with customizable design variables and theme switching. This improved my understanding of **scalable UI design and frontend architecture**.
