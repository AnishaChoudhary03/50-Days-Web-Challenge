# 🚀 Day 45 – Advanced Component Composition

Welcome to **Day 45 of my 50-Day Web Development Challenge!**

Today, I explored **Advanced Component Composition** using the native `<template>` and `<slot>` elements. The goal was to build reusable components that can accept dynamic content while keeping their structure consistent.

* Understanding the `<template>` element

* Passing dynamic content into components
* Combining Templates with Web Components

* Separating component structure from content
* Creating flexible and reusable UI components

## 🧩 Component Composition

A reusable component can define a common structure while allowing different content to be inserted through slots.

```text id="w8x3kp"
Reusable Component
       │
       ├── Header Slot
       │
       ├── Content Slot
       │
       └── Footer Slot
              ↑
       Dynamic Content
```
