# 🚀 Day 9 – Accessibility Standards

Welcome to **Day 9 of my 50-Day Web Development Challenge!**

Today, I focused on **Web Accessibility Standards** and learned how to design websites that are usable and accessible to a wider range of users.

* Keyboard navigation
* Focus states
* Sufficient color contrast
* Using descriptive link text
* Making interactive elements accessible
