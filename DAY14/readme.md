# 🚀 Day 14 – Dynamic Rendering

Welcome to **Day 14 of my 50-Day Web Development Challenge!**

Today, I explored **Dynamic Rendering using JavaScript** and learned how to generate and update webpage content dynamically instead of writing every element manually in HTML.

## 📌 What I Learned

* Creating HTML elements using JavaScript
* Using `createElement()`
* Using `appendChild()`
* Updating content dynamically
* Rendering lists and cards from JavaScript data
* Using loops for dynamic content generation
* Modifying the DOM based on user actions
* Removing and updating dynamically created elements
* Understanding the difference between static and dynamic content

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM API
* VS Code
* Git & GitHub

## 🎯 Day 14 Goal

The goal was to understand how JavaScript can dynamically create, update, and remove UI elements, making websites more **interactive, flexible, and data-driven**.



## 💡 Outcome

Successfully created a webpage that dynamically renders content using JavaScript and DOM manipulation.

This helped build a strong foundation for developing **interactive interfaces and data-driven web applications**.
