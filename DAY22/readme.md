# 🚀 Day 22 – Scroll Animation

Welcome to **Day 22 of my 50-Day Web Development Challenge!**

Today, I explored **Scroll Animations** and learned how to create engaging visual effects that are triggered as elements enter the user's viewport.

## 📌 What I Learned

* Detecting elements entering the viewport
* Using the `IntersectionObserver` API
* Creating reveal animations
* Adding CSS transitions and transforms
* Triggering animations based on scroll position
* Creating smooth fade-in and slide-in effects
* Improving user engagement through micro-interactions
* Combining JavaScript with CSS animations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Intersection Observer API
* CSS Transitions
* CSS Transforms
* VS Code
* Git & GitHub

## 🎯 Day 22 Goal

The goal was to create **smooth scroll-triggered animations** that enhance the visual experience without negatively affecting website performance.


## ✨ Key Features

* 👀 Elements animate when they enter the viewport
* ✨ Smooth fade-in effects
* ↔️ Slide-in animations

Successfully implemented scroll-triggered animations and learned how to combine **JavaScript, CSS transitions, and the Intersection Observer API** to create modern and engaging web experiences.
