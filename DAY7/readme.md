# 🚀 Day 7 – Form UI States

Welcome to **Day 7 of my 50-Day Web Development Challenge!**

Today, I focused on designing and implementing different **Form UI States** to make forms more interactive, user-friendly, and visually clear.

## 📌 What I Learned

* Designing clean and structured forms
* Default form state
* Focus state
* Hover state
* Valid input state
* Invalid input state
* Error messages and validation feedback
* Disabled state
* Success state
* Styling input fields and buttons
* Improving user experience through visual feedback

## 🛠️ Technologies Used

* HTML5
* CSS3
* Form Elements
* CSS Pseudo-classes
* VS Code
* Git & GitHub

## 🎯 Day 7 Goal

The goal was to understand how different form states communicate with users and provide clear visual feedback while filling out a form.



## 💡 Outcome

Successfully designed a form with multiple UI states, including **focus, error, success, disabled, and default states**, creating a more polished and user-friendly experience.
