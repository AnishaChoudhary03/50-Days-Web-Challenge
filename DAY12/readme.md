Welcome to **Day 12 of my 50-Day Web Development Challenge!**

* Toggling navigation visibility

* Responsive navigation design
* Combining JavaScript with CSS media queries
* Improving mobile user experience

* JavaScript

## 🎯 Day 12 Goal

The goal was to create a **functional mobile navigation menu** where users can open and close the navigation using a menu button.
