# 🚀 Day 16 – Local Storage

Welcome to **Day 16 of my 50-Day Web Development Challenge!**

Today, I explored **Local Storage in JavaScript** and learned how to store data in the browser so that it remains available even after refreshing or reopening the webpage.

## 📌 What I Learned

* Understanding browser Local Storage
* `localStorage.setItem()`
* `localStorage.getItem()`
* `localStorage.removeItem()`
* `localStorage.clear()`
* Storing and retrieving user data
* Converting objects using `JSON.stringify()`
* Reading objects using `JSON.parse()`
* Persisting data between page refreshes
* Combining Local Storage with DOM manipulation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM API
* Local Storage API
* VS Code
* Git & GitHub

## 🎯 Day 16 Goal

The goal was to understand how browser storage works and use **Local Storage to persist data** without requiring a backend database.



## 💡 Outcome

Successfully implemented Local Storage to save and retrieve data in the browser. This helped me understand how websites can **remember user preferences and information across sessions**.
